# 장금그룹 보험증권 취합 대시보드 · 개발 문서

**해상보험 증권·보험료를 한 화면에서 검색·집계하고, 각 줄에서 증권 원본 PDF를 바로 여는 사내 도구**의 공개 개발 문서입니다.

- **코드 리포(비공개)**: <https://github.com/SinokorOfficial/insurance-dashboard>

!!! note "공개 범위"
    이 사이트는 아키텍처·업무 규칙·데이터 모델·판독 로직 등 **개발 이해에 필요한 내용**만 다룹니다.
    운영 시크릿, 인프라 리소스명(IP·공유폴더·VNet·계정), **실제 보험료·부보금액** 등 사내 전용 정보는 포함하지 않습니다.

---

## 왜 만들었나

계열사 7개사, 선박 약 350척의 해상보험을 운영합니다. 증권 원본(PDF)은 사내 파일서버에 연도별·보험자별로 흩어져 있고, 보험료·부보금액은 별도 엑셀 두 개로 관리됩니다.

그래서 아래 질문에 답하려면 매번 손으로 여러 폴더와 엑셀을 뒤져야 했습니다.

- "이 배는 2022년에 어느 클럽 P&I였나? 증권 원본은 어디 있나?"
- "올해 계열사별 총 연간보험료는 얼마인가?"
- "선체보험 갱신일이 임박한 배가 어디 있나?"

## 한눈에 보는 시스템

| 영역 | 무엇을 |
|---|---|
| **조건 검색** | 계열사·보험종류·보험자·보험연도를 칩으로 다중 선택 + 선명·증권번호·IMO 검색 |
| **현시점 보험 정보** | 기준일에 **실제로 효력이 있는** 증권만 추림 (갱신일이 보종마다 달라 보험연도가 섞이는 것이 정상) |
| **통계·차트** | 검색 결과 기준 건수·척수·보험료·부보금액 + 연도별 추이 (통화별로 분리 집계) |
| **증권 원본 열기** | 표의 각 줄에서 그 선박·연도·보종의 실제 증권 PDF를 연다 |
| **사고 유형별 기초공제액** | 클럽 증권은 공제액이 유형별로 여러 개 — 버튼을 누르면 증권 원문과 함께 팝업 |
| **비고** | 줄마다 메모(50자). 재생성해도 살아남도록 별도 파일에 보관 |
| **내보내기** | 화면에 보이는 그대로 엑셀·CSV / 보기 전용 단일 HTML / 증권 PDF 포함 공유 패키지 |
| **선박·B/L·컨테이너 조회** | 사내 운항시스템 연동 탭 (환경변수로 켜고 끔) |

## 이 시스템의 성격

!!! info "DB가 없습니다"
    데이터는 **JSON 파일 한 개**입니다. 엑셀·증권 PDF를 읽어 이 파일을 통째로 다시 만드는
    **재생성 파이프라인**이 사실상의 ETL이고, 웹앱은 그 결과를 읽기만 합니다.

    - 원본이 사내 파일서버의 엑셀·PDF라 스키마가 계속 흔들립니다. DB에 넣어 두면
      원본이 바뀔 때마다 마이그레이션이 필요합니다.
    - 재생성이 **멱등**이라 언제든 처음부터 다시 만들 수 있습니다. 값이 이상하면
      원본을 고치고 다시 돌리면 됩니다.
    - 대신 "누가 언제 무엇을 바꿨나"는 못 남깁니다. 직접수정 이력만 레코드에 붙습니다.

## 기술 스택

| 레이어 | 기술 |
|---|---|
| 데이터 생성 | Python — `openpyxl`(엑셀) · `pypdf`/`pymupdf`(증권 판독) |
| 스캔 증권 판독 | Google Gemini (이미지 PDF는 정규식으로 못 읽는다) |
| 웹앱 | Flask + gunicorn, 단일 컨테이너 |
| 화면 | 순수 HTML/CSS/바닐라 JS — 빌드 도구·프레임워크 없음 |
| 저장소 | 사내 NAS(SMB) — 증권은 사외로 나가지 않는다 |
| 배포 | 컨테이너 이미지 → 사내망 도달 가능한 컨테이너 런타임, GitHub Actions 자동 배포 |
