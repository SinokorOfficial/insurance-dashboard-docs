# 데이터 모델

산출물은 레코드 배열 하나입니다. 한 레코드 = **한 담보**(BR-3).

## 필드

| 필드 | 설명 |
|---|---|
| `id` | 정수 고유키 (수정 대상 식별) |
| `계열사` | 정식 명칭으로 통일 (BR-5) |
| `소유주` `관리자` `용선자` | 선박 관계사 |
| `선명` | **컨테이너 레코드는 `null`** (BR-4) |
| `IMO` `선종` `건조연도` `톤수` `선적항` `선급` | 선박 기초정보 |
| `보험종류` | `HM` `IV` `HM/IV` `WAR` `P&I` `FDD` `MII` `MAP` `MII/MAP` `컨테이너` |
| `보험자` | 국내 손보 · 공제조합 · 국제 P&I 클럽 · 로이드 브로커 등 13종 |
| `증권번호` `보험연도` `보험시작` `보험종료` | 보험연도는 BR-2 |
| `부보가액` `보험료` `연간보험료` `기초공제액` `통화` | 금액. 통화는 `USD` 기본, 일부 `KRW` |
| `보험조건` | 자유 텍스트 메모 (공동보험·수량·선명 주석·공백 사유) |
| `서류종류` | **재실행 식별자로 쓰인다** |
| `원본파일` `원본경로` `원본목록` | `원본목록` = `[{파일명, rel}]`, `rel` 은 증권 폴더 기준 상대경로 |
| `추출출처` | 값의 출처. **후속 단계가 덮어쓴다 — 식별자로 쓰지 말 것** |
| `조합인수사` | 공제조합 공제를 인수한 손보사. 갱신일 판정에만 쓴다 (BR-9) |
| `공제상세` | `[{유형, 금액, 통화, 원문}]` — 사고 유형별 기초공제액 (BR-11) |
| `공제출처` | 그 공제액을 어느 증권에서 읽었는지 |
| `검토필요` | true면 통계 합산에서 제외 |
| `변경이력` | 직접수정 이력 |
| `비고` `비고수정` `_rkey` | **산출물에 없다.** 화면에 낼 때 비고 파일에서 합친다 |

## 금액 표기

보관값은 **정밀도를 그대로** 두고, 화면·엑셀 출력에서만 소수 2자리로 반올림합니다.

!!! example "왜 그렇게 하나"
    엑셀에 `39306.229999999996` 이 찍히던 문제가 있었습니다. 부동소수점 찌꺼기입니다.
    보관값을 반올림해 버리면 합산·재계산에서 오차가 누적되므로, **출력에서만** 다듬습니다.

## 통화가 섞여 있다

대부분 `USD` 지만 일부 담보가 `KRW` 로 청구됩니다.

- 통계 카드는 **통화별로 나눠** 합산합니다.
- 연도별 차트 막대는 **USD만** 그립니다. 환율 없이 더하면 금액이 부풀려집니다.
  실제로 한 해 막대가 30% 넘게 부풀어 보이던 버그가 있었습니다.
  USD 외 통화는 차트 아래에 통화별·연도별로 따로 적습니다.

## `서류종류` / `추출출처`

| `서류종류` | `추출출처` | 뜻 |
|---|---|---|
| `연간보험료(엑셀)` | `엑셀: 연간보험료` | 보험료 엑셀 기준 (24~26PY) |
| `과거연도 보완(보험현황)` | `보험현황(과거연도)` | 보험현황 시트 기준 2020~2023 |
| `P&I 보완(보험현황)` | `보험현황(2024 보완)` | 클럽만 확보, 보험료 미확보 |
| `증권` | `증권 판독(컨테이너 MMIP)` | 컨테이너 |
| `증권` | `증권 우선(조합공제 판독)` | 조합 증권만 있고 로스터에 없던 선박 |
| (위 유지) | `증권 우선(자동판독)` | **증권 판독이 값을 적용한 레코드** |
| (위 유지) | `직접수정` | 사람이 화면에서 고침 (BR-7) |

## 브라우저에 보내는 것은 일부뿐

레코드에는 필드가 30개 남짓이지만, **보기 전용 화면에는 화면이 실제로 쓰는 것만** 보냅니다.

통째로 보내던 때는 레코드 JSON의 **37%가 화면이 안 쓰는 값**이었습니다.
가장 컸던 `원본목록`은 서버가 이미 가공해 함께 보내던 **중복**이었습니다.

```
레코드 JSON   8.19 MB → 5.14 MB
```

빠지는 것: `원본목록` `원본파일` `원본경로` `보험조건` `추출출처` `검토필요` `변경이력`
`소유주` `관리자` `용선자` `조합인수사`

!!! warning "화면에서 새 필드를 쓰려면 허용 목록에 먼저 넣어야 합니다"
    안 넣으면 오류 없이 **조용히 빈칸**이 됩니다.

    담당자용 로컬 화면에는 적용하지 않습니다 — 수정 기능이 있어 전 필드가 필요하고,
    `추출출처`·`검토필요` 를 컬럼·배너·통계에 씁니다.
