# 화면 구성

세로로 카드가 쌓입니다.

| 카드 | 내용 |
|---|---|
| 🕒 **현시점 보험 정보** | 기준일에 효력이 있는 증권만. 켜면 아래 조건검색이 잠긴다 |
| 🔎 **조건 검색** | 계열사·보험종류·보험자·보험연도 칩 + 선명/증권번호/IMO 검색 |
| 📈 **통계** | 건수·척수·보험료·부보금액 카드 + 연도별 막대그래프 |
| ⚙️ **데이터 관리** | 담당자 전용 (재생성·내보내기·게시) |
| 📋 **보험가입 현황** | 본체 표 |

## 표

컬럼 16개를 그립니다.

```
계열사 · 선명 · 보험종류 · 보험자 · 증권번호 · 보험연도 · 보험시작 · 보험종료
부보가액 · 연간보험료 · 보험료 · 기초공제액 · 통화 · 기초정보 · 서류종류 · 비고
```

`기초정보` 는 선종·건조연도·톤수·선적항·선급·IMO를 한 칸에 조립한 것입니다.
맨 앞에는 그 줄의 증권을 여는 📎 링크가 붙습니다(여러 장이면 번호).

## 현시점 보험 정보 (as-of)

기준일에 **실제로 효력이 있는** 증권만 고릅니다.

```
보험시작 ≤ 기준일 ≤ 보험종료
```

- 갱신일이 보종마다 달라 **보험연도가 섞여 나오는 것이 정상**입니다 (BR-2).
- 이 모드에서는 **계열사만** 고를 수 있습니다.
- **선박이 아닌 책임보험 묶음(화주배상 등)은 제외**합니다. 몇 건 제외했는지 화면에 표시합니다.
- 켜져 있는 동안 조건 검색은 **잠깁니다**. 두 검색이 섞이면 연도가 뒤엉켜 잘못 읽힙니다.

!!! note "버튼을 새로 추가하면 잠금 목록에도 넣어야 합니다"
    현시점 모드의 격벽은 버튼을 하나씩 비활성화하는 방식이라, 새 버튼을 추가하고
    목록에 안 넣으면 격벽이 뚫립니다.

## 사고 유형별 기초공제액 팝업

클럽(P&I·FDD) 줄은 기초공제액 칸이 **버튼**입니다.

```
┌────────────┐
│ 15,000  ▾4 │   ← 이 증권에 공제액이 4가지 적혀 있다
└────────────┘
```

누르면 사고 유형별 공제액이 **증권 원문 문구와 함께** 나옵니다.

| 사고 유형 | 공제액 | 증권 원문 |
|---|---|---|
| 화물 | 12,000 USD | `R34 Cargo USD 12,000 Per voyage` |
| 선원 | 7,500 USD | `… R27 Crew USD 7,500 Per event` |
| 충돌 | 21,000 USD | `R36 Collision USD 21,000 Per event` |
| 기타 | 15,000 USD | `Other P&I liabilities USD 15,000 Per event` |

공동인수 프로그램(BR-10) 선박은 **1차 인수사 기준임을 알리는 안내문**이 함께 뜹니다.
공제액이 하나뿐인 줄(선체·전쟁·조합)은 예전처럼 숫자만 나옵니다.

## 비고

줄마다 메모(최대 50자). 칸을 벗어나거나 Enter를 누르면 바로 저장됩니다.

- **누가 써도 모두가 봅니다.** 로컬에서 쓴 것도 웹에서 쓴 것도 같이 보입니다.
- 마우스를 올리면 누가 언제 썼는지 나옵니다.
- **재생성해도 지워지지 않습니다** (별도 파일).
- 웹은 저장 직전에 저장소에서 다시 읽어 합칩니다 — 다른 사람이 방금 쓴 비고를 덮어쓰지 않기 위해서입니다.
- 오프라인 공유물에서는 **보기만** 됩니다(서버가 없어 저장할 수 없습니다).

## 내보내기

**화면에 보이는 것과 반드시 같은 행**을 내보냅니다.

!!! danger "이 일치는 과거 버그를 고치며 세운 규칙입니다"
    내보내기가 필터 함수를 직접 부르는 바람에, 현시점 모드인데도 **전체 건수가 나가던** 버그가 있었습니다.
    그래서 화면과 내보내기가 **같은 함수**를 보게 했습니다.

    화면 표시를 제한하는 장치를 넣을 때는 그 함수 단계에서 걸어야 합니다.
    렌더만 막으면 화면은 비었는데 엑셀은 전체가 나갑니다.

## 선박·B/L·컨테이너 조회 탭

사내 운항시스템 연동 탭입니다. **API 키 환경변수가 있을 때만** 나타납니다.

- **선박 조회** — 선명으로 스케줄 조회 + 그 선박의 보험자 교차조회
- **B/L 조회** — B/L 번호로 바로 조회
- **컨테이너 조회** — 컨테이너 이동이력

!!! note "응답에서 내보내는 항목을 목록으로 제한합니다"
    B/L 조회 원본 응답에는 칼럼이 200개 넘게 있고 환율·여신·정산 담당자명까지 들어 있습니다.
    화면에 안 보여도 응답에 실리면 공유 화면을 보는 사람에게 그대로 나가므로,
    **허용 목록에 있는 항목만** 통과시킵니다. 운임 금액은 아예 내보내지 않습니다.
